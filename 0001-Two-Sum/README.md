# 1. Two Sum

LeetCode Problem: 1. Two Sum https://leetcode.com/problems/two-sum/description/

Difficulty: Easy

Language: Java

Problem Description:  Given an array of integers nums and an integer target, return the indices of the two numbers such that they add up to the target.

Approach: Brute Force

1. Use two nested loops to check all possible pairs.
2. The outer loop selects the first element.
3. The inner loop selects the next element (j = i + 1).
4. Check if the sum of both elements equals the target.
5. If the condition is satisfied, return their indices.
